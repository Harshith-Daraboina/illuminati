# Time Table Automation System

A Python-based project to automate the generation of academic timetables for schools, colleges, or universities. The system is designed to reduce manual work, prevent scheduling conflicts, and provide an efficient, user-friendly interface for timetable management.

## Project Objective

To develop an automated timetable generator that assigns subjects to classrooms and teachers, while satisfying all constraints like teacher availability, subject requirements, and classroom limits.

## Features

- Auto-generation of class and teacher-wise timetables
- Prevents overlapping of classes and teacher assignments
- Supports multiple courses, departments, and batches
- Easy data entry through CSV or GUI
- Output in Excel format
- Extendable for elective subjects and lab scheduling
